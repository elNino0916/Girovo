# Girovo 5.2.1

## Fixes
- **Girovo opens at normal size again** – a zoom from Ctrl+- or Ctrl++ lasts until you close the app, and the next start is back at 100 %.
- **Zooming and resizing the window no longer fills the error reports** with a harmless browser notice – which used up the reports a real problem would have needed. The same error is now reported once per session instead of over and over.

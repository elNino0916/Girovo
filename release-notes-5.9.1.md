# Girovo 5.9.1

## Android
- **Xiaomi phones no longer count as rooted** – HyperOS mounts its own regional apps and settings over the system partition, and Girovo took that for a root modification: every Xiaomi phone showed "Dieses Telefon ist verändert" and kept nothing. Girovo now only counts such a layer when a root tool made it. OPPO and OnePlus phones, which do the same with their own partitions, are fixed too.

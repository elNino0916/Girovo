# Sooskasse-FinTS 4.2.1

A small follow-up to 4.2.0: the update window can no longer get lost behind other windows.

## Updates
- **The progress window stays in front.** While an update installs, its window now stays above your other windows until the new version is open, so it can't disappear behind your browser.
- **The first small download.** If you are on 4.2.0, this is the first update that downloads only what changed: a few megabytes instead of the whole installer.
- *The window that shows this update comes from the version you are updating from, so the "stays in front" behaviour starts with the update after this one.*

# Girovo 5.5.1

A fix for the input fields.

## Fixes
- **Fields no longer turn red on their own** – leaving an empty field, such as the PIN at the login, marked it red with the browser's "Fülle dieses Feld aus.". A field now only shows Girovo's own message, once there is something to fix.
- **No second frame inside a field** – while you type, a field shows only its own outline, not an extra blue box around the text.
- **One focus ring on buttons** – moving through buttons with the keyboard showed two rings around the focused one. Now there is one.
